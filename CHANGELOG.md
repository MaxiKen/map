# Changelog

Nigeria WebGIS uses [semantic versioning](https://semver.org/). Each released version has a matching
`vX.Y.Z` tag, a reproducible public build identifier, and a static-site release archive. Changes are
collected under **Unreleased** until `scripts/prepare_release.py` assigns a version and UTC date.

## [Unreleased]

### Added

- **Import GeoPackage.** **Import** sits in the Layers toolbar with Show all, Hide all, Fit visible, Clip, Grid, Labels and Basemap. It is the same size as those controls and does not cover them. A `.gpkg` file is read in the browser and is not sent anywhere. Its layers are listed under Imported, above On the map, and stay off until you turn one on. They can then be used with the published layers. Files in the usual Nigerian coordinate systems (WGS 84 and Minna UTM zones and belts) are converted to longitude and latitude. A Minna file uses the national shift, which is only good to about 15 metres, and that limit is shown when the file is read and kept on the imported layer.

- **Filter features** keeps one numbered list. Any layer that is switched on can be filtered, and a layer can hold more than one filter — they are combined, so a feature is drawn only if it matches every filter on that layer. Each filter can be edited or removed on its own. The same list sits at the top of the Layers panel. Legend “add as filter”, the attribute table and the temporal filter join that list instead of wiping it.
- Complete tool guide. **Tools -> Guide** (and **Guide** in About) documents every registered tool with
  what it does, the steps, a tip, what it needs, and the phone-versus-desktop gesture table; it can be
  searched. The same content is published as `docs/tools-guide.md`, generated by
  `scripts/gen_tools_guide.mjs` / `npm run docs:tools` so it cannot drift from the Tools panel.
- Select by area is a first-class mode with an on-map bar: tap to select or unselect one feature, drag a
  box to select many, then List / Zoom / Export CSV / Clear. The bar only exists in select mode; Done
  returns the map to normal panning. Documented and covered by desktop and phone tests.
- `window.__nwg` exposes the selection API (`enterSelectMode`, `exitSelectMode`, `selItems`, `selClear`,
  `selToggle`, `openSelectionList`) for scripting and support.
- Clip to an area did not work for the shapes it offers. Rectangle, Square, Circle
  and Freehand now draw a live outline as you drag and produce a real focus area. **Square** is square
  on the ground (equal kilometres a side, not equal pixels), **Circle** takes its radius in metres
  from the centre to where you release, and the area and edge numbers agree with that radius.
- **Clip → Pick features from a layer** is a real picker: it lists every polygon layer (with off layers
  marked), keeps your ticks when you switch layers, searches the list, zooms to a row, and clips to the
  union of everything picked — even across layers, as separate shapes rather than one broken polygon.
  **Pick on the map** turns the same choice into taps: tap shapes to add or remove them, Done returns
  to the ticked list, Cancel or Esc leaves everything as it was.
- Picking several features used to cancel itself out: area and edge length summed signed ring areas
  across shapes, so picks with opposite winding could total zero. Each picked shape now counts on its own
  (outer ring minus holes). A focus area also survives a reload, a map preset, a session code and a share
  link in every form — circle radius in metres included.

- **Exports are back, without location coordinates.** Selection, the selection list, select-by-area,
  attribute tables, statistics, charts, the area summary, measurements and every spatial-analysis result
  can be saved as CSV, JSON or a printable table. The quality panel downloads the register again. Every
  file is stripped of latitude, longitude and bounding boxes before it is written, and a file that still
  contains them is refused. Saved pictures leave degree labels and the centre coordinate off the caption.
  GeoJSON, KML and shapefile downloads stay unavailable.

### Fixed

- **Data and display tools do what they name, and the result stays on screen.** Count by Attribute and Field Stats by Group keep their tables in the open panel. Count and Compute are the buttons. Select by Attribute highlights the matching features. The attribute table sorts and a row tap locates the feature. Field Calculator adds a column from the expression, not from typed code. A saved picture does not write latitude or longitude on the grid.
- **Classification uses the method it names, and the classes stay on screen.** Natural Breaks is Jenks — the gaps in the numbers — not equal counts. Quantile keeps about the same number in each class, and identical values stay together. Equal Interval is equal steps from low to high, and an empty step is still listed. The table stays in the open panel. The layer is coloured with Cividis and can be restored. The source file is not edited. A hidden feature is not counted, and fewer distinct values are not padded with empty classes.
- **Reset the view returns to the opening extent.** Filters and the focus area go. A playing time slider stops, so the filter does not come back. Rotation returns north-up. The layer list and colours stay. Full screen uses the Tools button and the expand button as the same switch, and says so if the browser blocks it.
- **Generation tools draw the shape they name.** Fishnet and Regular Point Grid cover the view, or the focus area, with cells and points sized in kilometres on the ground. They are not a degree box around the centre, and a grid that would not fit is not drawn as a fragment. Random Points, Random Lines and Random Polygons stay inside that area. Hexagonal Binning counts points in hexagons, not squares. Random Sample draws a copy and leaves the source unchanged. Random Raster draws a surface of random cell values. It is not a measurement, and it is not added to the catalog.
- **Network tools follow the lines.** Shortest Path, Service Area, Trace, Network Buffer and Multi-Stop Route draw a route along the lines and leave the source unchanged. A crossing without a shared vertex is not a junction. Lengths are kilometres along the lines. Service Area and Network Buffer are not circles. Trace follows the stored direction and does not walk a line backward. Connectivity counts separate pieces and does not call a dead end a break. Merge joins a copy only where two ends meet. Bearing uses a compass from longitude and latitude, weighted by length. Betweenness ranks junctions by shortest paths, not by how many lines touch. Distance Matrix stays in the panel and is the straight line, not a road.
- **Topology checks do what they name, and they stay on screen.** Overlap, gaps, validity, self-intersection, duplicates, null geometry, out of bounds, multi-part, ring direction and within-distance write a named result in the open panel. A check does not draw and does not edit the source. A gap is a hole the polygons enclose, not a cell outside them. Distances and the duplicate tolerance are metres or kilometres on the ground. Longitude and latitude are tested as degrees, not as the map’s internal units. Snap, Snap to Grid, Spatial Join Count and Remove Small Polygons draw a copy and leave the source unchanged. A hole is subtracted from area and is not counted as a second part. Feature Erase and Buffer Dissolve are unchanged.
- **Overlay tools do the operation they name.** Intersect, Dissolve, Polygon Union, Feature Erase and Buffer Dissolve share one result panel: a count, the area, a table, and CSV, JSON or a printable table with no coordinates. Union removes shared borders. Difference cuts the overlapping piece out of each polygon instead of dropping the whole feature. The second layer starts on a different layer, and opening another tool cancels a run that is still going.
- **Geometry tools do what they name.** Feature Centroid, Densify, Split by Line, Concave Hull, Affine, Lines to Polygons, Outlines, Smooth, Buffer, Bounding Box, Vertices to Points, Points Along Lines and Line Offset draw a new shape and leave the source unchanged. Distances are kilometres on the ground. Area & Perimeter subtracts holes. Adjacency counts a shared border. Area, adjacency and line length stay in the panel and say so. Polygon Union is unchanged.
- **Raster tools do what they name.** Raster Calculator, Reclassify, Clip, Slope, Clip by Polygon and Overlay Math draw a new surface on the raster and leave the original layer unchanged. Contours are lines on the raster, not at the page corner. Statistics, Histogram, Class Zonal and Raster Difference stay in the panel and say so. The calculator does not run typed code.
- **Sharing tools do what they name.** Share View copies a link that reopens the centre, zoom, basemap, catalog layers, focus area and grid. It does not carry colours, filters, notes or an imported file, and it says so. Session Codes save the map in this browser under a 6-character code, and the longer code carries that session so someone else can paste it. There is no server. Map Notes add a marker you can drag. Notes stay in this browser. They are not a layer, and they are not in a share link.
- **Time and accessibility tools do what they name.** Temporal Filter and Time Slider turn a layer on if needed, keep the map visible, and write a real year filter instead of hiding features by hand. Stop removes that filter. A source time period is listed separately and is not treated as a year field. Accessibility applies as you change it and is kept in this browser. Screen Reader announcements follow the switch. Colorblind Palettes paint or classify the layer you pick, and do not offer a red-against-green ramp.
- **Search and discovery tools do what they name.** Feature Finder searches the layers that are on, can include one layer that is off without showing it, and opens Info on the feature you pick. A filter or a focus is respected unless you ask otherwise. Coordinate Inspector reads a tap on the map, not a covered panel, and the readout can be copied. Coordinate Converter keeps decimal degrees, degrees-minutes-seconds and a named grid in step, including WGS 84 UTM and Minna, and a Minna value shows the 15-metre limit. Layer Discovery searches names, sources and column names, and Show, Hide and Zoom are separate.
- **Cartography tools do what they name.** Color Ramps classifies with the ramp you picked — including Cividis — instead of silently falling back to another palette, and it colours lines as well as fills. A custom basemap is registered on reload, cannot replace a built-in, and requires an https XYZ URL plus attribution. Map Presets restore colours, filters, opacity and layer order, and say when a layer or basemap is not in this browser. Print Layouts letterbox the map onto A4, A3 or Letter instead of stretching it, and the picture still has no latitude or longitude.
- **The remaining analysis tools use that same panel, and measure what they claim.** Nearest Neighbor keeps searching until a nearer feature is impossible, and a point inside a polygon is 0 km. Count Points in Polygons counts a point on a shared border in every polygon that contains it, and says so. Convex Hull encloses lines and polygons by their outline and can draw one hull per group. Simplify Geometry works on lines as well as polygons, in metres, and leaves the original layer unchanged. Zonal Statistics keeps the sample count separate from the cells that sample stands for, adds a median, and never treats NoData as zero.
- A temporal **On or after** or **Equals** filter now uses the year you typed. It used to compare against an empty bound, so it did not match the features it named.
- **Rectangle** and **Current view** now actually clip the map. `focusFromRect`, **Current view** and the
  legend's **Focus on it** built the box with its top and bottom swapped, which the engine refused, so the
  app reported a focus area in the toast while the map kept drawing everything. The engine now accepts the
  two corners in either order, keeps the bbox in its own top/bottom order, and `setFocus` says so when a
  shape cannot be used instead of announcing an area it never applied.
- Area summary, selection and analysis results can be exported again. The files never include latitude or longitude.
- **Selection could not pick polygons** on either layer: the map kept panning during a box drag and the
  Info panel named the geometry kind instead of the layer. Select mode now owns the pointer while it is
  on, boxes select every feature inside them, and Info card headers name the layer the feature came from.
- The clip drag handlers read the drawing state after it had already been cleared, so rectangle, square
  and circle never produced a focus area at all. The shape is captured before the state is reset.
- `polyOverlapsPoly` misread a polygon whose rings are typed arrays as one flat coordinate list, so
  polygon-inside-polygon tests (buffer, clip, erase, overlay) returned false everywhere.
- Buffer zones carried a bounding box mixed from degrees and mercator units, making every buffer look
  about ten degrees wide. Buffer, erase and overlay hit-tests are now accurate and grid-indexed.
- Field dropdowns in Count by Attribute, Field Stats by Group and the three classifiers listed
  "[object Object]" instead of column names, so no field could be chosen. They now show real columns
  (classifiers list numeric columns only).
- Tools that used to hang or crawl on a large layer now finish in seconds: Distance Matrix and
  Multi-stop Route sample instead of taking every pair, Zonal Statistics and Spatial Join scan raster
  cells or points once against a spatial grid, and Check Overlaps, Check Gaps, Polygon Adjacency,
  Duplicate Geometries, Self-Intersections, Snap, Split Polygons and Count Points no longer compare
  every feature with every other one. The full 125-tool browser sweep dropped from a hang to under two
  minutes.
- Work in progress is announced in the toast with a name ("Checking 775 polygons…") and always replaced
  by a real result, so no tool can leave a permanent "working" message.
- **Buffer / Proximity is chosen on the map.** Tap the point, line or polygon — there is no list of identical names. If several features sit under the tap, the list shows the details that tell them apart. The zone can be a circle, square, diamond or hexagon.
- **Spatial analysis tools do the operation they name.** Buffer / Proximity works on one chosen feature
  and summarises everything inside its zone, from the same layer and from every other layer that is on.
  Intersect reports the real overlapping area. Nearest neighbour measures edge to edge. Dissolve unions
  shared borders and keeps the gaps. Count points and zonal statistics test the polygon itself, including
  holes. Simplify honours the kilometre tolerance. Polygon overlay uses an inlined polygon-clipping library.
- Restrict mutable source-fetch workflows to main-branch pushes or manual dispatch so release tags and
  pull-request branch pushes never fetch and commit replacement data.
- Correct the EMAG2 future-fetch mask's height/width order, exercise the failed non-square grid, and make the
  seven-layer geology refresh manual-only. The 98% coverage guard still refuses unreviewed partial data.

### Removed

- All application GeoJSON acquisition controls: expanded-layer and Quality-panel links, single-feature JSON export,
  and visible-layer GeoJSON export. Rendering/fallback artifacts, source provenance, user-owned GeoJSON import,
  CSV/PNG export and the non-geometric quality-register download remain intact.

## [1.0.0] - 2026-11-08

### Added

- Stable `ngmap-admin-v1` identifiers and parent joins for states, LGAs and wards, with a conservative
  external INEC crosswalk and complete unresolved-link provenance.
- The `ngmap-cross-border-v1` policy covering all 98 source layers, including explicit transboundary,
  regional-reference, marine, raster-window and Nigeria-only aggregation rules.
- The `ngmap-layer-quality-v1` JSON/CSV/Markdown register and an interactive Quality & source UI with
  measured checks, source metadata, limitations, licence evidence, hashes and metadata gaps; no numeric
  quality score or invented missing metadata.
- Deterministic gzip transport sidecars, bounded layer loading, module-worker parsing/conversion and a
  compatible yielding fallback. Original GeoJSON downloads remain available.
- Real-Chromium interaction, gzip-worker, offline-reload, service-worker update and desktop/mobile visual
  regression tests with no external tile dependency.
- One-command maintenance verification, byte-reproducible public-build checks, release preparation and
  deterministic static-site ZIP/manifest/checksum packaging.

### Changed

- Reviewed state-capital positions, polygon topology, ward/LGA attributes and hidden-source artifacts now
  carry guarded ledgers, before/after hashes, stable provenance and read-only verification.
- EMAG2 magnetic coverage is explicitly presented as partial rather than implying continuous national
  coverage. Raster values and source geometry were not interpolated or silently repaired.
- Public exports and the service-worker shell are versioned together. Network-first catalog/register/data
  responses use their last good cached copy offline, and controlled updates reload once without a hard
  refresh or manual cache clearing.
- CI validates source/public artifacts, Python and Node regressions, real Chromium behavior and visual
  baselines. The same validation workflow is reusable by tag releases.

### Fixed

- Worker vector requests use application-root data URLs rather than resolving below `/js/`.
- First-visit service-worker installation caches the catalog for offline reload, and a subsequent update
  in that visit is no longer suppressed by the initial controller state.
- Source links are restricted to HTTP(S), quality content is escaped, and unclassified vector styling uses
  an explicit neutral fallback instead of failing in the legend.
