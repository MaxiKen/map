## Interpretation and maintenance

- `hidden_historical_provenance` and `hidden_source_restricted` layers are not public production layers.
- `current_with_documented_limits` requires the listed scope/coverage caveats; it is not a defect score.
- `metadata_status` counts six source fields only. It does not judge geometric quality or licence clearance.
- GeoPackage SHA-256 values make stale source/register combinations detectable. Any data or metadata change requires both audits, this register, and the public build to be regenerated sequentially.
- Source metadata: `config/layer-metadata.json`. Full evidence: `layer-quality-register.json` and `layer-quality-register.csv`. Cross-border rules: `cross-border-policy-register.csv`.
- For an inventory change, run one provisional public build before this register so public-export fields are current. The second extended-audit pass includes the current register in the item 8 report.

```bash
python scripts/audit_geospatial.py
python scripts/audit_geospatial_extended.py
python scripts/layer_quality_register.py
python scripts/audit_geospatial_extended.py
python scripts/build_site.py
python scripts/validate_artifacts.py
python -m unittest discover -s tests -v
```
